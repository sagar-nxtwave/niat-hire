NIAT website - plain HTML version

Files:
- index.html
- assets/slide-01.webp ... slide-12.webp

How to run locally:
1. Keep index.html and the assets folder together.
2. Double-click index.html, or run a local server:
   python3 -m http.server 8000
3. Open http://localhost:8000

Deployment:
- Vercel: deploy this folder as a static site.
- Netlify / GitHub Pages: upload the same folder.

Navigation:
- Scroll / trackpad
- Up and down arrow buttons
- Keyboard Arrow Up / Arrow Down / Page Up / Page Down / Home / End

Final slide CTA:
- The visible button is part of the Adobe design image.
- A transparent HTML link is overlaid on top and currently opens:
  mailto:hiring@nxtwave.tech
- Change that href in index.html if you want a form URL or another destination.
